# Intent: mkmusic

## Outcome
A personal web music player with a Spotify/YT Music-inspired dark mode UI. Features include:
- Search and stream YouTube tracks (audio-only, ad-free).
- Netflix-style multi-profile selection (e.g., Markus & Pacar).
- Player controls (Play, Pause, Seek, Volume, Queue / Up Next, Shuffle, Repeat).
- Lyrics view (Lirik Lagu).
- Trending / Popular Chart discovery.
- Mood / Genre discovery categories.
- Personal playlists and saved favorites per profile.

## User
- Primary user and partner (Pacar).

## Why Now
To enjoy a feature-rich, Spotify Premium / YT Music streaming experience without ads or recurring subscription fees.

## Success
- Profile switcher on app launch (select user profile).
- Fast YouTube track search and audio playback without ad interruptions.
- Lyrics display and queue management.
- Playlist management per profile with cross-device sync.
- Smooth responsive dark UI.

## Constraint
- Web application deployable seamlessly to Vercel (Next.js / React).
- Lightweight cloud database (e.g., Supabase or Upstash KV) for profile & playlist synchronization.
- Zero ad interruptions.

## Out of Scope
- Monetization / Payment integration.
- Advertisements.
- Heavy YouTube video playback (audio-focused).
- Public social networks / public profile feeds.
